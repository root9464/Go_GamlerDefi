## 1. Подключение

Клиент должен установить WebSocket-соединение по следующему URL:

`ws://<your_server_address>/api/session/ws/:session_id/:user_id`

**Параметры URL:**

*   `:session_id` (string): Уникальный идентификатор игровой сессии, полученный после ее планирования через REST API.
*   `:user_id` (string): Уникальный идентификатор пользователя, который подключается.

При успешном подключении сервер добавит игрока в сессию. Первый подключившийся к сессии игрок автоматически становится **Ведущим (Host)**.

## 2. Формат сообщений

Взаимодействие происходит через единую точку входа — событие `game_action`. Клиент отправляет действия на это событие, а сервер слушает его. Сообщения от сервера к клиенту приходят в виде обертки `EventWrapper`, которая содержит тип события и полезную нагрузку.

### 2.1. Клиент -> Сервер

Все действия от клиента должны быть отправлены на событие `game_action` и иметь следующую структуру:

```json
{
  "event": "game_action",
  "data": {
    "type": "имя_действия",
    "payload": { ... }
  }
}
```

*   `type` (string): Имя действия, которое нужно выполнить.
*   `payload` (object): Объект с данными, необходимыми для выполнения действия.

### 2.2. Сервер -> Клиент

Все сообщения от сервера приходят в виде обертки `EventWrapper` и **не привязаны к конкретному имени события на клиенте**. Клиент должен слушать общее событие `message` и парсить JSON, чтобы определить тип по полю `type`.

```json
{
  "type": "имя_события",
  "payload": { ... }
}
```

*   `type` (string): Имя события, которое произошло на сервере.
*   `payload` (object): Объект с данными, описывающими событие.

## 3. События и действия базового шаблона

Эти события и действия являются общими для всех игр, построенных на данном шаблоне.

### 3.1. События, которые слушает клиент (Сервер -> Клиент)

#### `full_state`
*   **Когда:** Только один раз, новому подключившемуся игроку.
*   **Описание:** Содержит полное состояние игровой сессии. Клиент должен использовать это событие для первоначальной отрисовки всего игрового поля.
*   **Payload (`FullGameStatePayload`):**
    ```json
    {
      "sessionId": "string",
      "gameTitle": "string",
      "players": [
        {
          "id": "string",
          "name": "string",
          "isHost": true,
          "position": { "x": 0.1, "y": 0.1 },
          "hand": [ /* массив объектов Card */ ],
          "metadata": { /* объект с кастомными данными */ }
        }
      ]
    }
    ```

#### `player_joined`
*   **Когда:** Всем "старым" игрокам, когда к сессии подключается новый участник.
*   **Описание:** Уведомляет клиентов о появлении нового игрока. Клиент должен добавить фишку нового игрока на поле.
*   **Payload (`PlayerJoinedPayload`):**
    ```json
    {
      "player": { /* полная структура Player нового игрока */ }
    }
    ```

#### `player_left`
*   **Когда:** Всем оставшимся игрокам, когда кто-то отключается.
*   **Описание:** Уведомляет клиентов об уходе игрока. Клиент должен убрать фишку этого игрока с поля.
*   **Payload (`PlayerLeftPayload`):**
    ```json
    {
      "playerId": "string"
    }
    ```

#### `token_moved`
*   **Когда:** Всем игрокам, когда кто-то передвинул свою фишку.
*   **Описание:** Сообщает новые координаты фишки одного из игроков. Клиент должен обновить позицию соответствующей фишки на поле.
*   **Payload (`TokenMovedPayload`):**
    ```json
    {
      "playerId": "string",
      "position": { "x": 0.5, "y": 0.6 }
    }
    ```

#### `dice_rolled`
*   **Когда:** Всем игрокам после того, как кто-то бросил кубики.
*   **Описание:** Сообщает результаты броска кубиков.
*   **Payload (`RollDiceResponse`):**
    ```json
    {
      "client_id": "string",
      "dices": {
        "faces": 6,
        "value":
      }
    }
    ```

#### `prompt_select_card`
*   **Когда:** Только одному игроку, когда Ведущий предлагает ему выбрать карту из колоды.
*   **Описание:** Команда для клиента показать интерфейс выбора карты.
*   **Payload (`PromptSelectCard`):**
    ```json
    {
      "id": "deck_1",
      "name": "Колода Сокровищ",
      "back_image_url": "https://example.com/card_back.png",
      "cards": ["card_101", "card_102", "card_103"]
    }
    ```

#### `card_revealed`
*   **Когда:** Всем игрокам, когда кто-то решает показать свою карту.
*   **Описание:** Показывает всем карту, которую раскрыл один из игроков.
*   **Payload (`CardReveal`):**
    ```json
    {
      "card": { /* полная структура Card */ }
    }
    ```

#### `game_rules_updated`
*   **Когда:** Всем игрокам, когда Ведущий меняет правила игры.
*   **Описание:** Уведомляет об изменении правил, например, количества кубиков.
*   **Payload:**
    ```json
    {
        "diceCount": 2,
        "facesNumber": 12
    }
    ```

### 3.2. Действия, которые отправляет клиент (Клиент -> Сервер)

#### `move_token`
*   **Кто:** Любой игрок.
*   **Описание:** Сообщает серверу о новой позиции фишки игрока после перетаскивания.
*   **Payload (`MoveToken`):**
    ```json
    {
      "position": { "x": 0.7, "y": 0.3 }
    }
    ```

#### `roll_dice`
*   **Кто:** Любой игрок.
*   **Описание:** Запрос на бросок кубиков в соответствии с текущими правилами игры.
*   **Payload:** `{}` (пустой)

#### `select_card`
*   **Кто:** Игрок, который получил событие `prompt_select_card`.
*   **Описание:** Ответ игрока на запрос выбора карты.
*   **Payload (`SelectCard`):**
    ```json
    {
      "deck_id": "deck_1",
      "card_id": "card_102"
    }
    ```

#### `show_everyone_card`
*   **Кто:** Любой игрок.
*   **Описание:** Игрок хочет показать всем одну из карт у себя на руке.
*   **Payload:**
    ```json
    {
      "card_id": "card_in_hand_45"
    }
    ```

### 3.3. Действия только для Ведущего (Host)

#### `change_dice`
*   **Кто:** Только Ведущий.
*   **Описание:** Изменяет правила броска кубиков для всех в сессии.
*   **Payload (`ChangeDice`):**
    ```json
    {
      "dice_count": 3,
      "faces_number": 8
    }
    ```

#### `get_decks`
*   **Кто:** Только Ведущий.
*   **Описание:** Запрашивает у сервера список всех доступных в игре колод.
*   **Payload:** `{}` (пустой)

#### `give_deck_for_selection`
*   **Кто:** Только Ведущий.
*   **Описание:** Заставляет сервер отправить игроку `player_id` запрос на выбор карты из колоды `deck_id`.
*   **Payload (`GiveDeckForSelection`):**
    ```json
    {
      "deck_id": "deck_1",
      "player_id": "user_abc"
    }
    ```

## 4. Специфичные действия для игры "Sales Courage"

Эта игра использует все базовые действия и добавляет свои собственные.

### 4.1. Действия, которые отправляет клиент (Клиент -> Сервер)

#### `add_coins`
*   **Кто:** Только Ведущий.
*   **Описание:** Добавляет (или списывает, если число отрицательное) монеты указанному игроку. Эти монеты хранятся в `player.metadata`.
*   **Payload:**
    ```json
    {
      "player_id": "user_abc",
      "coins": 10
    }
    ```
